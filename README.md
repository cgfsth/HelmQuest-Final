# BoatPhysics3D

<div align="center">
  <img src="./public/images/helmquest-preview.png" alt="Boat Simulation Preview" width="600"/>
</div>

MarineSim3D is a 3D boat simulation project built using Three.js. It features realistic water physics, wave interaction, and buoyancy effects within a tropical island environment. This project is designed for educational purposes and for those interested in game development and marine simulations.

## Features

- **Realistic Boat Physics**: Advanced buoyancy and wave interaction simulation
- **Training Mode**: Interactive training modules with guided missions
- **Post-Docking Quiz System**: Automated assessments after key training milestones
- **3D Environment**: Tropical island setting with dynamic water rendering
- **Progress Tracking**: Student progress saved and tracked throughout training

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Technology Stack

- **Three.js**: 3D graphics and rendering
- **Vue 3**: UI framework with Composition API
- **Vite**: Build tool and development server
- **JavaScript/ES6+**: Core programming language
